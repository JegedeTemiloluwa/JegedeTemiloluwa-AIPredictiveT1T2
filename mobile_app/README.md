# DiaGuard AI - Type 1 Diabetes Prediction Mobile App

DiaGuard AI is a premium mobile application designed for early risk assessment of Type 1 Diabetes using a high-performance machine learning model.

## Features
- **AI-Powered Diagnostics**: Interfaces with a FastAPI backend hosted on Render.
- **Modern UI**: Clean, minimalist medical aesthetic built with Flutter and Google Fonts.
- **Secure Storage**: Local tracking of prediction history.
- **Real-time Analysis**: Instant feedback based on clinical metabolic features.

## Technical Stack
- **Frontend**: Flutter (Dart)
- **Backend**: FastAPI (Python/XGBoost)
- **State Management**: Provider
- **Networking**: Http package with JSON serialization.

## Deployment
The app is configured to connect to the live AI server at `https://aipredictivet1t2.onrender.com`.

## Installation
To install the app on your Android device, use the APK found at:
`build/app/outputs/flutter-apk/app-release.apk`
